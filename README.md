# DevOps-Lab04

## คำอธิบายโครงการ

เว็บไซต์ **IT Care** เป็นหน้าเว็บตัวอย่างสำหรับบริการ IT Support ช่วยให้ผู้ใช้ดูข้อมูลบริการและกรอกรายละเอียดเพื่อแจ้งปัญหาด้านไอที เช่น คอมพิวเตอร์ อุปกรณ์สำนักงาน เครือข่าย อินเทอร์เน็ต โปรแกรม และบัญชีผู้ใช้ ออกแบบให้ใช้งานง่าย รองรับหน้าจอทั้งคอมพิวเตอร์และโทรศัพท์มือถือ

## คุณสมบัติ

- แสดงข้อมูลและประเภทบริการ IT Support
- มีแบบฟอร์มแจ้งปัญหา พร้อมช่องกรอกข้อมูลผู้แจ้ง ประเภทปัญหา ระดับความเร่งด่วน และรายละเอียด
- ตรวจสอบช่องข้อมูลที่จำเป็นก่อนแสดงข้อความยืนยัน
- ปรับรูปแบบหน้าเว็บให้เหมาะกับหน้าจอขนาดต่าง ๆ

> หมายเหตุ: แบบฟอร์มนี้เป็นตัวอย่างสำหรับสาธิตการทำงานบนหน้าเว็บเท่านั้น ยังไม่ได้เชื่อมต่อฐานข้อมูลหรือระบบรับแจ้งปัญหาจริง
